# Wilfried Koba — Photographe & Graphiste

Site portfolio professionnel, en HTML/CSS/JS statique, hébergé sur GitHub Pages.

## Structure

```
index.html
assets/
  css/style.css
  js/script.js
  images/            photos du portfolio (mariages)
```

## Publier / mettre à jour le site

1. Modifier les fichiers (`index.html`, `assets/css/style.css`, `assets/js/script.js`).
2. Ajouter/remplacer les photos dans `assets/images/`.
3. Committer et pousser sur la branche `main`.
4. GitHub Pages republie automatiquement le site (Settings → Pages → Branch: `main` / `root`).

## Contenu à compléter

- Coordonnées (téléphone, réseaux sociaux) dans la section Contact (`index.html`).
- Ajouter les photos des autres univers (corporate, événementiel, graphisme) dans `assets/images/` et la galerie.
